## Sobre o projeto

Este repositório reúne atividades práticas e códigos desenvolvidos durante os estudos de **Algoritmos e Pensamento Computacional**.

O objetivo é aplicar conceitos fundamentais da programação para desenvolver o raciocínio lógico, estruturar soluções para problemas computacionais e compreender como transformar requisitos em algoritmos executáveis.

Entre os códigos disponíveis está uma calculadora desenvolvida em linguagem C, utilizada para praticar operações matemáticas, entrada e saída de dados e organização da lógica de um programa.

## Objetivos de aprendizagem

- Desenvolver o raciocínio lógico e computacional.
- Compreender a sequência de execução de um algoritmo.
- Praticar a declaração e utilização de variáveis.
- Trabalhar com operadores aritméticos e expressões.
- Aplicar estruturas condicionais e de repetição conforme a necessidade de cada atividade.
- Aprimorar a escrita, a organização e a legibilidade do código-fonte.

## Como executar

### Pré-requisitos

- Compilador C instalado, como o GCC.
- Terminal ou ambiente de desenvolvimento compatível.

### 1. Clone o repositório

```bash
git clone https://github.com/ArtPie-dev/Algoritmos-e-Pensamento-Computacional.git
```

### 2. Entre na pasta

```bash
cd Algoritmos-e-Pensamento-Computacional
```

### 3. Compile a calculadora

O nome do arquivo contém espaços. No terminal, utilize aspas:

```bash
gcc "calculora em c.c" -o calculadora
```

### 4. Execute o programa

No Linux:

```bash
./calculadora
```

No Windows, utilizando GCC:

```bash
calculadora.exe
```

Se o arquivo tiver sido renomeado, ajuste o comando de compilação conforme o nome atual.
